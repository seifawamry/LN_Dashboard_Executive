# Infant Formula Market Volume & Liptis Nutrition Analytics Dashboard

An interactive, responsive data analytics web application tracking infant formula market volume sales and competitive performance (YTD May 2025 vs. YTD May 2026), with a focus on **Liptis Nutrition**'s product portfolio.

## 🚀 Live Demo & Deployment
- **Deployment Platform**: [Vercel](https://vercel.com)
- **Tech Stack**: HTML5, Modern Vanilla JavaScript, Responsive Tailwind CSS, Pure SVG Charts & Visuals (zero external runtime dependencies).
